# ⛄ Snowman Skater

**Snowman Skater** is a complete HTML5 browser game built entirely with **vanilla HTML, CSS, and JavaScript**.

The game was generated from a **single AI prompt** and features 3D-perspective gameplay, **30 levels, power-ups, animations, local storage persistence, and responsive controls**.

Players control a snowman skater, navigate through obstacles, collect power-ups, and progress through increasingly challenging levels.

## 🎮 Features

* ⛄ Snowman-themed skating gameplay
* 🛹 3D-perspective gameplay
* 🎯 30 levels with progressive difficulty
* ⚡ Power-ups and special abilities
* 🎬 Animations and visual effects
* 🏆 Score and level progression
* 💾 Local Storage for persistent game progress
* 📱 Responsive design
* ⌨️ Keyboard controls
* 🌐 Runs directly in a web browser
* 🚫 No external frameworks or game engines required

## 🛠️ Technologies

* **HTML5** — Game structure and UI
* **CSS3** — Styling, animations, and visual effects
* **JavaScript** — Game logic, controls, levels, collision detection, scoring, and persistence
* **Local Storage API** — Saving game progress

## 🚀 Getting Started

### Clone the repository

```bash
git clone <repository-url>
cd snowman-skater
```

### Run the game

No installation or build process is required.

Open `index.html` directly in a modern web browser.

You can also use a local development server such as VS Code Live Server.

## 🎮 How to Play

Control the snowman as he skates through each level.

Avoid obstacles, collect power-ups, earn points, and reach the end of each level to progress.

### Controls

| Action     | Control             |
| ---------- | ------------------- |
| Move Left  | `←` / `A`           |
| Move Right | `→` / `D`           |
| Jump       | `↑` / `W` / `Space` |
| Pause      | `P`                 |
| Restart    | `R`                 |
